# LoL 逐局规则与开播核对

本轮参考 HOK main `751b2c8`，在 LoL main `89e92d0` 上适配通用比赛工作流。

## 操作

1. 在「比赛设置」选择 BO1 / BO3 / BO5 / BO7。BO7 四胜结束，比分方框自动显示四格。
2. 展开 Control「逐局规则管理」，编辑系列默认，或选择 Game 1–7 设置单局覆盖。星号表示单局覆盖，锁表示该局已经开始或完成。
3. 每局可配置赛事五 Ban / 练习两 Ban、Normal / Team Fearless / Player Fearless、先手方、换边展示、是否执行此前英雄限制、是否把本局英雄计入后续限制。英雄仍使用 Riot Champion ID 和 LoL 分路。
4. 点击「保存逐局规则」。本局尚未开始时立即生效；未来局在「下一局」时自动应用。开始的局会冻结有效规则；修改系列默认时，界面自动为已锁定局保留覆盖。
5. 启用逐局规则后，普通比赛设置中的 BP 规则为只读，请回到逐局规则管理修改。整场重置保留规则计划，Undo 可撤销保存。整场尚未开始或重置整场后，可点击「停用逐局计划」恢复固定规则设置；当前有效规则仍保留。变更系列长度前，请移除超出长度的未来局覆盖；已完成历史仍锁定赛制。
6. 开播前展开「开播预检」，检查连接与十名选手 ID，并对照游戏房间逐一确认 P1–P5。本页勾选不是 OCR 或 LCU 成功证明；换局、名单、顺序或分路变化会使它失效，刷新页面也需重新核对。此提醒不阻断手动 BP。

提交历史保存当局规则快照。关闭某局「计入后续限制」不会删除历史；未来局只是不再从该记录累积 Fearless 限制。关闭「执行此前限制」仅影响本局，之后的规则独立计算。已完成局不能事后排除。

## OBS 图形

英雄变化前预加载并解码当前图片来源与本地头像，最多等待两秒。保留最多十二个图片条目；快速改选、撤销或组件卸载会取消旧揭幕回调。加载失败继续使用已有头像 fallback。初次打开、减少动态效果、修改图源本身沿用现有静态展示；预加载不构成离线 Splash Art 保证。

## 范围

保留 LoL Champion Studio、LCU API 自动 BP、手动录入、Caster 延迟与原有 LoL 选禁顺序。本轮没有加入 HOK 专用 HUD/OCR、中立资源、盲选、赛后评分、Discord 投票或 OBS 远程控制。这些功能需要 LoL 数据接口与真实赛事样本的独立适配。

## 实机彩排

更新后执行 `npm ci`、`npm run build`，重启服务器并刷新 Control / Caster / OBS。依次彩排 BO7 四胜、Game 2 覆盖、红方先手、换边、Undo、重启恢复，以及实际 League Client 和 OBS 浏览器源。浏览器测试不能代替 Windows / LCU / OBS 实机验收。
